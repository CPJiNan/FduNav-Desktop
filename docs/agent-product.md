# Agent 产品化改造与验收

基线：CPJiNan/FduNav-Desktop `1f854d0`（2026-11-05）。工作分支：`feat/agent-product`。

范围：工具协议、执行预算、重试与取消、usage、上下文压缩、长期记忆、流式输出、审批写入撤销，以及执行轨迹侧栏。包含 eLearning 已有同步与待办查询的修复；新增邮件接入、云同步、多 Agent、向量库与运行时依赖不在本次范围。修改计划中的建议是输入材料，最终按本文件记录的实现与证据验收。

## 产品约束

- 查通知、读取通知、查课表/日程、查待办使用真实工具；无结果和数据陈旧必须告知。
- 新建日程/待办、保存/删除记忆仍须用户允许。pending 不能声称写入成功。
- 每个工具结果包含成功状态、错误分类、截断信息和剩余预算。耗尽预算后只允许总结已取得的结果。
- 仅模型请求可重试；流式内容一旦输出，不自动重放，以免重复文本或调用。
- 轨迹按会话与账号隔离：时间、耗时、轮次、工具参数、原始工具结果、提供给模型的结果、审批、错误、压缩、usage。密钥与认证头不可记录。侧栏不声称展示隐藏思维链。
- 原始工具结果和模型上下文结果分开保留，截断明确可见。正文流式增量刷新，工具参数组装完成且校验后才执行。
- 长期记忆存本地；启用后选中的内容随对话发送给配置的模型服务。删除记忆不等于删除旧会话中已有的副本，清空会话可清除后者。
- 摘要是有损上下文；原始历史仍可在轨迹中检查。压缩失败可降级，但必须在轨迹中标明。
- 撤销先比较实际记录与 checkpoint，记录已被用户修改则拒绝覆盖；审批状态和写入同事务保存，重复点击不重复写入。
- 模型请求按消息和工具定义去重保存脱敏的不可变快照；详情读取时解析本地引用，存储 hash 不进入模型上下文。保留各次兼容回退的实际请求、原始响应和最终 assistant 消息。
- 完成、拒绝、失败、撤销和异步摘要结果以账号隔离的状态增量持久化，压缩成功吸收后推进独立水位；旧轮次被压缩后仍能传递新状态。
- 记忆更新需有明确的用户原话；撤销更新恢复原记录。缓存只保存 id，使用前重新检查内容、有效期、归档状态和统一预算。整理只撤销实际应用的组。
- 通知正文按 nextOffset 连续分段读取，避免长正文整体被结构摘要替换。审批回传使用精简视图，不透传完整 checkpoint 或同步元数据。
- 保留 provider 返回的 reasoning_content（含空字符串），用于要求回传此字段的工具调用协议。没有返回此字段的模型保持原有格式。
- 会话轨迹不再自动限制为 50 轮；清空会话时一并删除请求快照和状态增量。此前版本已清理的轨迹无法恢复。

## 验收矩阵

| 维度 | 场景 | 最低验收 |
| --- | --- | --- |
| 任务完成 | 检索通知后读正文；查今天课程；按明确日期创建日程/待办 | 使用正确工具；缺参数询问；写入需批准 |
| 工具正确 | 非法 JSON/未知字段/错误类型/读不存在记录/超长结果/预算耗尽 | 结构化错误；不重复副作用；可收尾 |
| 结果质量 | 空结果/截断/待批准/拒绝/撤销/记忆关闭 | 文案与实际状态一致；无假成功 |
| 稳定性 | 429/5xx/断网/断流/取消/设置变化/切换账号/进程重启 | 有限重试；及时停止；不执行不完整工具；中断可诊断 |
| 过程检查 | 实时查看与重启后打开历史轨迹 | 参数、原始响应、模型实际收到的响应、错误与耗时可查 |
| 隐私与数据 | 双账号、记忆导入导出、清空会话、冲突撤销 | 隔离、验证与本地删除；密钥不进轨迹 |

## 验证证据

已完成实现并通过自动化验证：`tsc`（node + web）无错误，`npm test` 全部通过，覆盖工具协议、预算收尾、压缩降级、审批与撤销、轨迹隔离等主流程。尚未完成：真实学校账号与模型服务的联调、打包构建与界面回归；不把 mock 通过写成真实任务成功率。
